SA do 3º Semestre (IoT)

Desenvolvi um projeto utilizando um ESP32 para coleta de dados ambientais, como temperatura, umidade do ar, luminosidade e umidade do solo. A comunicação entre o dispositivo e a aplicação foi realizada através do protocolo MQTT. Os dados coletados eram processados em uma aplicação desenvolvida em Java e exibidos em tempo real. Além disso, as informações eram enviadas para o Node-RED, permitindo a visualização e monitoramento remoto dos dados de qualquer lugar através da rede.

SA do 4º Semestre

Desenvolvi uma aplicação web utilizando Java com Spring Boot, JPA e Thymeleaf. O sistema possui uma interface completa de CRUD (Create, Read, Update e Delete), permitindo cadastrar, visualizar, editar e excluir dados. Para a interface do usuário utilizei HTML, CSS e Bootstrap, criando páginas responsivas e organizadas. O banco de dados utilizado foi MySQL, responsável pelo armazenamento e gerenciamento das informações da aplicação.

Linux

Como projeto profissional, realizei a instalação e configuração do Asterisk em ambiente Linux para a implementação de uma central telefônica PABX. Durante o processo, compilei o Asterisk a partir do código-fonte, instalei as dependências necessárias e configurei manualmente os arquivos do sistema. Utilizando editores de texto no Linux, criei e gerenciei ramais, além de definir as configurações da central PABX, possibilitando a comunicação entre os usuários do sistema.
